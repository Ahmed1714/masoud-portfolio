# M. — Masoud Hub

تطبيق أندرويد شخصي بالبراندينج بتاعي: لوجو Masoud، أسود `#080808` × أصفر دهبي `#FCCC00` × تركواز `#3DD8CB`، وخطوط الموقع (Cormorant Garamond · DM Sans · DM Mono) — كل حياتي اليومية في مكان واحد، **بيشتغل أوفلاين** وبيزامن مع **Notion** أول ما النت يرجع.

## الذكاء الاصطناعي
من الإعدادات اختار المزوّد وحط الـ API key بتاعك (بيتحفظ على الموبايل بس):
- **Claude** — `console.anthropic.com` (الافتراضي Claude Opus 5.5، وفيه Sonnet 5.5 و Haiku 5.5 أرخص وأسرع)
- **ChatGPT** — `platform.openai.com`
- **Gemini** — `aistudio.google.com`

## الربط بـ Notion
1. ادخل `notion.so/my-integrations` واعمل Integration جديد وانسخ الـ Secret.
2. اعمل صفحة في Notion (مثلاً *Masoud Hub*) ومن `⋯ ← Connections` ضيف الـ Integration.
3. في التطبيق: الإعدادات ← Notion ← حط الـ Secret ولينك الصفحة ← **اربط واعمل الجداول**.

التطبيق بيعمل 5 جداول: المهام، اليوميات، المصروفات، الأفكار، المحتوى. كل تعديل بيتحفظ على الموبايل الأول، ويتعلّم عليه (نقطة دهبي) لحد ما يترفع لـ Notion. المزامنة بتشتغل لوحدها لما النت يرجع، أو لما تفتح التطبيق، أو كل 5 دقايق، أو لما تدوس على زرار الحالة اللي فوق.
> المزامنة من التطبيق ← Notion (التعديل والحذف بيوصلوا). التعديلات اللي بتتعمل في Notion نفسه مش بترجع للتطبيق.

## تحميل الـ APK
كل push على فولدر `masoud-hub/` بيشغّل GitHub Action اسمه **Build Masoud Hub APK**.
ادخل GitHub ← Actions ← آخر run ← **Artifacts** ← `masoud-hub-apk` ← فك الضغط وسطّب `app-debug.apk` على الموبايل (اسمح بالتثبيت من مصادر غير معروفة).

## التطوير
```bash
cd masoud-hub
npm install
npm run dev          # تجربة على المتصفح
npm run cap:sync     # بناء ونسخ للأندرويد
npx cap open android # فتح في Android Studio
```

**التقنيات:** React + TypeScript + Vite، Capacitor 8 (أندرويد)، Dexie (IndexedDB) كقاعدة بيانات محلية، Notion API، Anthropic SDK.
نص المصحف من حزمة `quran-json` (المصدر: موسوعة القرآن الكريم quranenc.com).
