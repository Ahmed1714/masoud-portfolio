# أوترو PUVANA – سكربت After Effects

## التشغيل
1. خلي الملفين `PUVANA_Outro.jsx` و `puvana_logo.png` في نفس الفولدر.
2. افتح After Effects ← File ← Scripts ← Run Script File… واختار `PUVANA_Outro.jsx`.
3. هيتعمل كومب `PUVANA_Outro` (1920×1080، 30fps، 6 ثواني) جاهز، اعمل File ← Save As عشان تحفظ ملف `.aep`.

> لو ظهرت رسالة صلاحيات: Edit ← Preferences ← Scripting & Expressions ← فعّل "Allow Scripts to Write Files and Access Network".

## الأنميشن
| الوقت | الحدث |
|---|---|
| 0.00 | نقطة مية تيل بتنزل من فوق |
| 0.55 | ارتطام: موجات مية (Ripples) + رذاذ |
| 0.60 | إطار ذهبي بيرسم شكل البادج من فوق |
| 1.10 | اللوجو يظهر بقلبة 3D + ارتداد مرن |
| 1.25 | لمعات ذهبية تنفجر حوالين اللوجو |
| 2.20 | ضوء لامع (Shine) يعدي على اللوجو |
| 2.40 | التاجلاين + خطين ذهب |
| حتى النهاية | Push-in بطيء سينمائي |

## التعديل
أول السكربت في جزء `CFG`: المدة، حجم اللوجو، نص التاجلاين (اكتب "" لإلغائه)، الخط، و `fadeOut` للاختفاء للأبيض في الآخر.
