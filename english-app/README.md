# English Master - تطبيق تعلم اللغة الإنجليزية

تطبيق أندرويد لتعلم وحفظ مفردات اللغة الإنجليزية باستخدام التكرار المتباعد (Spaced Repetition).

## المميزات

### 🗂️ فئات المفردات
- 6 فئات جاهزة: الحياة اليومية، الطعام والشراب، السفر، الأعمال، المشاعر، والتكنولوجيا
- 120 كلمة مع الترجمة العربية وجملة مثال لكل كلمة

### 🃏 البطاقات التعليمية (Flashcards)
- نظام تكرار متباعد (خوارزمية SM-2) لجدولة المراجعة تلقائياً
- تقييم الإجابة: مرة أخرى / صعب / جيد / سهل
- جلسة مراجعة يومية للكلمات المستحقة

### 📝 اختبارات (Quiz)
- اختبار اختيار من متعدد (4 خيارات) لكل كلمة
- اختبار سريع مكوّن من 10 كلمات مختلطة، أو اختبار مخصص لكل فئة
- تقرير نتيجة فوري في نهاية الاختبار

### 📊 التقدم
- إحصائيات شاملة: كلمات جديدة، قيد التعلم، قيد المراجعة، متقنة
- نسبة الإتقان الكلية ونسبة الدقة

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| Kotlin + Jetpack Compose | واجهة المستخدم الحديثة |
| Room Database | حفظ المفردات والتقدم محلياً (بدون إنترنت) |
| Hilt | حقن الاعتمادات |
| Navigation Compose | التنقل بين الشاشات |
| MVVM Architecture | تنظيم الكود |

## خوارزمية التكرار المتباعد

يعتمد التطبيق على نسخة مبسطة من خوارزمية SM-2:
- عامل السهولة (Ease Factor) يبدأ من 2.5 ويتغيّر حسب أداء المستخدم
- الفاصل الزمني بين المراجعات يكبر تدريجياً (1 يوم ← 6 أيام ← أضعاف عامل السهولة)
- تُصنَّف الكلمة "متقنة" عندما يتجاوز فاصل المراجعة 21 يوماً مع إجابات صحيحة متتالية

## طريقة البناء والتثبيت

### المتطلبات
- Android Studio Hedgehog (2023.1.1) أو أحدث
- JDK 17
- Android SDK 34
- هاتف أندرويد 8.0+ أو محاكي

### خطوات البناء

```bash
# 1. افتح المجلد في Android Studio
File > Open > english-app/

# 2. انتظر تحميل Gradle (أول مرة يأخذ وقتاً)

# 3. ابنِ APK
Build > Build Bundle(s) / APK(s) > Build APK(s)

# 4. ستجد الـ APK في:
app/build/outputs/apk/debug/app-debug.apk
```

## الشاشات

1. **الرئيسية** - إحصائيات سريعة، بطاقة مراجعة الكلمات المستحقة، اختبار سريع، وقائمة الفئات
2. **الفئة** - قائمة كلمات الفئة مع أزرار بدء البطاقات التعليمية أو الاختبار
3. **البطاقات التعليمية** - جلسة مراجعة بنظام التكرار المتباعد
4. **الاختبار** - اختبار اختيار من متعدد مع تقرير النتيجة
5. **التقدم** - لوحة إحصائيات شاملة
